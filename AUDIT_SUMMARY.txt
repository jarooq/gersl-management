CRITICAL ISSUES (Implement This Week) - 8 Items
================================================================================

1. HR MODULE - Department Distribution Hardcoded
   Location: src/pages/HR/HRPage.jsx (Lines 219-225)
   Issue: 7 departments with hardcoded counts and percentages
   Fix: Use staff.reduce() to calculate from HRContext data
   Impact: Shows incorrect department distribution

2. HR MODULE - Leave Types Hardcoded  
   Location: src/pages/HR/HRPage.jsx (Lines 264-268)
   Issue: 5 leave types with hardcoded counts
   Fix: Aggregate leaveRequests by leaveType
   Impact: Leave statistics don't reflect actual data

3. PROJECTS MODULE - Status Distribution Hardcoded
   Location: src/pages/Projects/ProjectsPage.jsx (Lines 247-250)
   Issue: "Planning" (3) and "On Hold" (2) counts are hardcoded
   Fix: Calculate from projects.filter() by status
   Impact: Project status dashboard shows incorrect numbers

4. PROJECTS MODULE - Programme Areas Hardcoded
   Location: src/pages/Projects/ProjectsPage.jsx (Lines 215-218)
   Issue: Programme budgets hardcoded (CP: 5M, Edu: 3.5M, etc)
   Fix: Sum project budgets grouped by programmeArea
   Impact: Budget distribution chart is inaccurate

5. PROPOSALS MODULE - Missing Donor Integration
   Location: src/pages/Proposals/ProposalsPage.jsx
   Issue: No PartnersContext import; donors are freetext input
   Fix: Import PartnersContext, create dropdown from partners
   Impact: Can't enforce valid donor selection

6. PROPOSALS MODULE - Missing CBO Integration
   Location: src/pages/Proposals/ProposalsPage.jsx
   Issue: No CBOContext import; cboName is freetext input
   Fix: Import CBOContext, create dropdown from cboPartners
   Impact: Can't enforce valid CBO selection

7. TASKS MODULE - Missing Project Context
   Location: src/pages/Operations/TasksPage.jsx (Lines 34, 62)
   Issue: Project names hardcoded; no ProjectContext import
   Fix: Import ProjectContext, use projects.map() for dropdown
   Impact: New tasks can't select from actual projects

8. TASKS MODULE - Missing HR Context
   Location: src/pages/Operations/TasksPage.jsx (Lines 35, 63)
   Issue: Assignees hardcoded; no HRContext import
   Fix: Import HRContext, use staff.map() for assignee dropdown
   Impact: Can't assign tasks to actual staff members

BONUS - ORPHANS MODULE - Missing CBO Context
   Location: src/pages/Orphans/OrphansPage.jsx
   Issue: No CBOContext import; can't link orphans to CBOs
   Fix: Import CBOContext for orphan-CBO relationships
   Impact: Limited orphan care management functionality
