## ⚠️ Known Limitations

### **1. No Backend Integration**
- Currently all data is stored in Context (in-memory)
- Data resets on page refresh
- No persistence layer yet
- **Solution:** Add backend API (Node.js + MongoDB or PostgreSQL)

### **2. Limited User Management**
- Hardcoded users in constants file
- No dynamic user creation
- No password reset
- **Solution:** Integrate with backend auth system

### **3. No Real-Time Collaboration**
- No multi-user awareness
- No conflict resolution
- **Solution:** Add WebSocket support

### **4. No File Upload**
- Cannot attach documents
- No image uploads for orphans
- **Solution:** Add file upload API

### **5. No Reporting Engine**
- No PDF export
- No Excel downloads
- Limited print layouts
- **Solution:** Add reporting library (jsPDF, xlsx)
